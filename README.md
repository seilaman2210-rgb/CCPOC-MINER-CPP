### How to run:

*Download the latest release, and run:*

> ./plotter_cpu <size in gb> <threads>

e.g. "./plotter_cpu 1 8"

*Now just wait for plot to generate!*

### Requirements

> You need the wallet.json created by PoC-Mini-Miner.py at the same folder the plotter is.
